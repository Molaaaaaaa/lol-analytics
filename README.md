# 솔랭 해체 분석기

> 해체하여, 지식을 습득한다.

친구 그룹의 League of Legends **솔로랭크** 전적을 Riot Match-V5 / Timeline-V5 데이터로
분석해 보여주는 정적 사이트입니다.

**사이트**: https://lol-disassembly-analyzer.pages.dev/
(예비: https://molaaaaaaa.github.io/lol-analytics/)

## 무엇을 보여주나

첫 화면에서 닉네임을 고르면 그 사람의 분석이 열립니다.

- **명예의 전당** — 최다 킬·최고 CS·최대 딜·최속 승리 같은 개인 기록
- **챔피언 / 맞라인** — 잘 되는 챔프, 상대하기 어려운 챔프
- **아군 · 적** — 같이 하면 이기는 챔프, 적으로 만나면 힘든 챔프
- **오브젝트** — 용을 몇 마리 언제 어떤 걸 먹었을 때 이겼는지, 오브젝트 영향력
- **죽음의 지도** — 킬/데스 좌표 히트맵 (블루 진영 기준으로 정규화)
- **피솔킬** — 어시스트 없이 혼자 잡힌 죽음. 판당 피솔킬 · 판당 솔킬 · 수지,
  가해자 라인(맞라이너/정글/로밍), 시간대 분포, 나를 가장 잘 잡는 챔피언
- **습관과 리듬** — 연승·연패, 죽어 있던 시간 비율, 시간대별 승률
- **실력 향상 피드백** — 같은 경기 직접 상대 비교 × 역할 평균 대비 약점 탐지

## 집계 기준

- **솔로랭크(queue 420)만**, 10분 미만 경기 제외
- 최근 경기에 가중치 (최근 30판 3배 / 31~100판 2배 / 그 이전 1배)
- 표본이 적은 항목은 참고용입니다 — 6판짜리 승률은 흔들립니다
- **피솔킬** = 어시스트 0인 CHAMPION_KILL 의 피격 방향. 라이엇 `challenges.soloKills`
  와 같은 규칙이며, 400경기 4,000행에서 정확일치 100%로 확인했습니다

## 기여하기

### ⚠ `index.html`은 직접 고치지 마세요

`index.html`은 파이썬 스크립트가 **자동 생성**하는 결과물입니다.
직접 수정해도 다음 갱신 때 통째로 덮어써집니다.

### 디자인 · 레이아웃을 고치고 싶다면 → `templates/site.html`

화면을 그리는 HTML · CSS · JavaScript는 전부 이 파일에 있습니다.
**여기를 고쳐서 PR을 보내주시면 다음 빌드부터 반영됩니다.**

```
templates/site.html   ← 화면을 고치려면 여기
PATCHNOTES.md         ← 바꾼 내용을 여기에 적으면 사이트 첫 화면에 나옵니다
index.html            ← 자동 생성물 (건드리지 마세요)
```

### 패치 노트

무엇을 왜 고쳤는지 `PATCHNOTES.md` 에 남깁니다. 이 파일은 빌드할 때 파싱되어
첫 화면 아래 **패치 노트** 칸에 그대로 뜹니다. 형식은 이것뿐입니다.

```markdown
## 2026-08-21
### 추가
- 무엇을 넣었는지
### 수정
- 무엇이 틀렸고 어떻게 고쳤는지
```

쓸 수 있는 머리말은 `추가` · `수정` · `개선` · `사고` 넷입니다.
`**굵게**` 와 `` `코드` `` 만 먹히고 나머지 마크다운은 그대로 글자로 나옵니다.

파이썬을 몰라도 됩니다. HTML/CSS만 알면 충분합니다.
`__DATA__` 라는 자리표시자에 분석 데이터(JSON)가 주입되므로 그 부분만 지우지 마세요.

### PR 보내는 법

저장소가 공개라 **초대받을 필요 없습니다.** 포크 → 수정 → PR 이면 됩니다.

### 의견 · 버그 제보

코드를 건드리지 않고 말만 남기고 싶으면 **Issues** 탭을 써주세요.
"이 지표 이상해요", "이런 거 보고 싶어요" 전부 환영합니다.

## 데이터 생성

지표 계산과 사이트 생성은 별도 프로젝트(`lol-coach-agents`)에서 수행하며,
